## ✨ Key Features

- **100% Offline-First Architecture**: Zero budget, no external servers or paid APIs required.
- **Strict Single-Viewport UI**: Built with Jetpack Compose using modern non-scrolling card layouts and bottom navigation.
- **Deep Curriculum**:
  - Cybersecurity Fundamentals (CIA triad, risk formula, least privilege)
  - Phishing & Social Engineering (Sender domain analysis, lookalike links, QR scams)
  - Password Security & Passphrases (Passphrase generation, password vaults, 2FA)
  - Network & Wi-Fi Security (HTTPS/TLS, public Wi-Fi risks, VPNs)
  - Web & Application Security (OWASP Top 10, SQLi, XSS, session security)
  - Mobile Security & Device Protection (Permission auditing, sideloading risks, SIM PIN)
  - Digital Privacy & Identity (Data minimization, social media privacy)
  - Digital Payments & UPI Fraud Awareness (UPI PIN rules, QR scams, 1930 helpline)
- **5 Interactive Defensive Practice Labs**:
  - Phishing Email Inspector
  - URL & Link Trust Analyzer
  - Password Strength Evaluator
  - App Permission Auditor
  - UPI Payment Scam Simulator
- **Gamification & Progress**:
  - Total XP, Leveling system (`1 + XP / 100`), Daily Streaks, and 6 Unlockable Badges.
- **Offline Certificate Generator & Exporter**:
  - Earn official course certificates and export high-res credential images to device storage or share via native Android share intents.
